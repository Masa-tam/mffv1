# Security Policy

mffv1 is pre-release software, but security and correctness reports are
welcome.

## Reporting

Use GitHub Issues for ordinary reports once the repository is public. If a
report involves sensitive video input, unreleased creative work, commercial
project material, personal data, or other confidential content, contact the
maintainer first and share only the minimum information needed to arrange a
safe disclosure path.

Prefer synthetic, minimized, or redacted reproducers over original media. Do
not upload private media, FFmpeg source code, or generated data with unclear
licensing to a public issue.

For details, see [Support Policy](docs/SUPPORT_POLICY.md).
